# 问道长生

一款可直接游玩的水墨风单人文字修仙游戏。由选择推进时间，无强制等待；从青云山洞府起步，踏上仙、魔、妖三途之一，历经三十二次破境，渡劫飞升真仙。

[在线体验](https://wendao-xiuxian-20261029.lovely-bell-1891.chatgpt.site)（私人站点）

## 启动

安装 Node.js 22 或更新版本。业务代码、测试与开发脚本均为 TypeScript，开启严格类型检查；浏览器运行的 JavaScript 由构建生成。

```powershell
npm.cmd ci
npm.cmd run dev
```

打开 http://localhost:4173 。开发服务首次构建后监听 `src/` 与 `public/`，保存文件会重新编译，刷新浏览器查看结果。

`npm.cmd run typecheck` 检查源代码、测试与脚本的类型；`npm.cmd test` 运行规则测试；`npm.cmd run build` 编译到 `dist/`，可部署到静态网站托管平台。构建后用 `npm.cmd start` 启动静态服务。

## 已实现玩法

- 洞府：吐纳、三日闭关、静养、采药与突破。
- 仙途百业：本命法宝认主、契合、器灵觉醒与首领试炼；三途27节点天赋与15项神通（最多配3项、可设置自动条件）；洞府四建筑与四块药田；丹道、炼器、符箓、阵法十二配方（最多精修两艺）；五种灵兽、亲密与两次进化；炼体神识共用点数；三宗九师、四级身份、委托和设施；27段道心经历与六种命格（最多生效2–3枚）。材料稳定采集或由首领保底产出，药田按游戏日成熟。
- 挑战难度：45本均增加精英与噩梦，逐级通关解锁，共135个难度组合。高难增加养成材料与奖励，普通真印成就独立。新增养成受共享上限约束，详见 [百业与挑战数值审核](GROWTH_BALANCE.md)。
- 破境演出：每次小阶段突破有灵气汇聚、阵纹扩散；跨大境界有劫云与三道天雷，大乘飞升有四道天雷。仙、魔、妖采用不同灵光配色，成功与失败分别收束。支持跳过、设置关闭和系统减少动态效果；设置中可无损预览天雷。
- 山河副本：九境各五本，共 45 本；每轮小怪、岔路机缘、精英、营地和首领五关，带蓄力预警及雷霆 / 毒瘴 / 汲血 / 狂暴 / 灵甲机制。首通保底指定本境法宝、真印、双倍基础灵石与额外山河令，同境五印集齐激活永久属性。支持按材料侧重刷本和山河令指定兑换任意已解锁法宝。
- 自动战斗与刷本：支持 1 / 5 / 10 / 20 轮，智能施展神通、法宝和御剑、预警守心；战中服丹和局间静养可独立开关。可随时暂停、停止或撤离，战败与超长战斗停止。刷新、切后台、多标签页更新自动暂停，无离线消耗。
- 数值重整：固定各境世界曲线、副本护甲递减收益、修炼收益随境界阶段同步成长、静养与丹药按上限恢复；奖励衔接功法、同境装备、淬炼、洗练与灵根。详见 [数值审核](BALANCE.md)，可执行 `npx tsx scripts/balance-audit.ts` 重跑 2025 场固定种子模拟。
- 藏经阁：仙魔妖每条路径、每个境界各 10 本原创功法（含真仙共 270 本），另保留原有 3 本通用根基，并新增 3 本宗门传承（均占十卷兼修位，已学重数离宗保留）。每本五重，同时最多兼修 10 本；封存、转修均保留已学重数。支持路径 / 境界 / 门类 / 已学状态筛选、关键词检索与分页，并展示周天合效。
- 坊市与行囊：购丹、服丹、出售灵材、采药炼丹。
- 灵装法宝：八个修炼大境界及真仙终点各一套武器、法衣与佩饰，共二十七件装备；九境各三十种通用法宝，共 270 种；装备有仙魔妖独立道纹，同境两件与三件激活不同套装效果。支持穿戴、三重淬炼、掉落与坊市按境界购买，法宝提供十类带冷却的战斗主动技能，被动与主动效果按角色同境初 / 中 / 后 / 圆满成长（100% / 115% / 130% / 150%）；跨境后旧宝保留圆满，真仙为终点初成。图鉴与坊市支持境界、效用、拥有状态筛选、检索、分页和阶段对照。
- 词条洗练：全部 27 件装备、270 件法宝均可洗出三条不同类型的词条，具有凡 / 灵 / 玄 / 道 / 仙五档品质；支持最多锁定两条、保留原词条或采用候选。候选随存档保存，刷新不重抽。词条仅穿戴时生效，法宝词条随阶段成长。洗练石可由采药、战斗、奇遇获得或购入。
- 灵根养成：首次测灵免费选择金木水火土主灵根，五行均可培养。引灵、采药和历练积累灵魄，凝露草可炼洗灵露；支持洗炼提纯、凡 / 真 / 天 / 仙四品晋升及保留进度的主灵根重塑。灵根影响修炼、突破、属性、御剑、回血回灵和护盾，不占十卷兼修位。
- 三途问道：仙修偏回元与修炼、魔修偏爆发与汲血、妖修偏体魄与护盾，各有本命神通与结局，法宝不分路径；首次择道免费，可付费改修。
- 成长：大境界沿用《凡人修仙传》主线——炼气、筑基、结丹、元婴、化神、炼虚、合体、大乘；按本游戏规则，每境统一为初期 / 中期 / 后期 / 圆满。大乘圆满后渡飞升天劫，踏入真仙终点；六个一次性里程碑任务。
- 存档：每次成功操作后自动保存，支持 JSON 导入导出、进度校验和二次确认重开。
- 界面：原创 SVG 山水、响应式布局、原生键盘可用对话框、角色状态、分类纪事。

存档保存在当前浏览器的 LocalStorage；本机与线上地址各有独立存档。换浏览器、换设备或清理网站数据前请先导出备份。没有账号、付费、广告和服务器存档。

## 文件

`src/types.ts` 定义角色、战斗、装备与路径类型；`src/growth.ts` 定义八业规则，`src/growth-content.ts` 为目录，`src/growth-view.ts` 为界面，`src/growth-combat.ts` 对接战斗，`src/growth-validation.ts` 严格校验存档；`src/dungeons.ts` 定义九境副本、首领、奖励、自动策略及校验，`src/dungeons-view.ts` 提供列表与战局，`src/balance.ts` 集中定义世界曲线与恢复；`src/affixes.ts` 定义洗练、锁定、词条效果与校验，`src/affixes-view.ts` 提供工坊与候选对照；`src/roots.ts` 定义灵根数值、材料、培养及校验，`src/roots-view.ts` 呈现五行养成页；`src/realms.ts` 统一定义境界、阶段与飞升；`src/engine.ts` 是与页面分离的游戏规则；`src/content.ts` 存放路径与装备数值；`src/artifacts.ts` 定义法宝与阶段成长，`src/artifact-library.ts` 负责图鉴与数值对照；`src/manuals.ts` 定义三途道藏与兼修效果；`src/app.ts` 负责页面与交互；`src/breakthrough-scene.ts` 生成突破结果快照，`src/breakthrough-effects.ts` 用 Canvas / SVG 播放原创演出。`public/` 保留 HTML、CSS 与美术资源；`scripts/*.ts` 负责构建与开发服务；`tests/*.test.ts` 覆盖数值、战斗、完整结局和存档迁移。`dist/` 为生成文件，不提交到 Git。

美术资产均随项目提供。字体优先加载 Google Fonts 的思源宋体和思源黑体，无法连接时自动使用系统中文字体，不影响游玩。

当前存档版本为 v10。v1–v9 保留全部既有角色、功法、装备、法宝、灵根、词条候选、首领战局和自动配置，补充未启用的八业记录与初始材料；没有自动认主、分配天赋、领取首通或恢复气血。当前成长与高难进度、药田成熟日、神通冷却和师承均可导入导出。此前 v9 新增副本进度、首领回合、山河令、真印收藏与自动配置；刷新后须手动恢复自动行动，既有战局不重置。v1–v8 保留全部既有养成和未完战局，不补发首通、不治疗、不清空进度。此前 v7 保留全部灵根培养进度，补充空词条库与 8 洗练石；原装备与法宝不自动改写词条，候选结果和锁定状态可完整导入导出。v6 及更旧角色补充未觉醒灵根与 12 灵魄、2 洗灵露；测灵前不改变原有属性、修为、物品或战局，旧角色无需重开。v5 的六件旧法宝保留原 ID、拥有记录、淬炼等级、装备、当前资源与战局，取消路径限制；阶段成长不会因读档而额外回血回灵。v4 自动将已学的通用三卷纳入兼修，保留重数、气血、灵力、物品与战局；不需要重开。v5 严格校验兼修上限、路径、境界与功法重数。v1 / v2 保留对应初、中、后期，金丹更名结丹，原渡劫境转为大乘同阶段；v3 炼气一至四层对应初期、五至七层对应中期、八至十层对应后期、十一至十三层对应圆满。已通关角色保持通关并进入真仙。保留修为完成比例、物品强化、日志与进行中的战斗，当前气血灵力及护盾只在超过新上限时裁剪，不因转换恢复。原装备 ID 和 LocalStorage 键不变，不必重新开局。
