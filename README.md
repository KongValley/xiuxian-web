# 问道长生

一款可直接游玩的水墨风单人文字修仙游戏。由选择推进时间，无强制等待；从青云山洞府起步，踏上仙、魔、妖三途之一，历经四十一次破境，渡劫飞升真仙。

[在线体验](https://wendao-xiuxian-20261029.lovely-bell-1891.chatgpt.site)（私人站点）

## 启动

安装 Node.js 18 或更新版本，无第三方运行依赖。

```powershell
npm.cmd run dev
```

打开 http://localhost:4173 。`npm.cmd test` 运行规则测试；`npm.cmd run build` 生成 `dist/`，可部署到静态网站托管平台。也可执行 `node scripts/server.mjs`。

## 已实现玩法

- 洞府：吐纳、三日闭关、静养、采药与突破。
- 山河：四张按境界解锁的地图，随机论道、遗藏和回合制战斗。
- 藏经阁：吐纳、剑术、炼体三类功法，各五重。
- 坊市与行囊：购丹、服丹、出售灵材、采药炼丹。
- 灵装法宝：八个修炼大境界及真仙终点各一套武器、法衣与佩饰，共二十七件装备、六件法宝；装备有仙魔妖独立道纹，同境两件与三件激活不同套装效果。支持穿戴、三重淬炼、掉落与坊市按境界购买，法宝提供带冷却的战斗主动技能。
- 三途问道：仙修偏回元与修炼、魔修偏爆发与汲血、妖修偏体魄与护盾，各有本命神通、专属法宝与结局；首次择道免费，可付费改修。
- 成长：采用《凡人修仙传》原著主线境界——炼气、筑基、结丹、元婴、化神、炼虚、合体、大乘；炼气十三层，筑基起初期 / 中期 / 后期 / 大圆满。大乘圆满后渡飞升天劫，踏入真仙终点；六个一次性里程碑任务。
- 存档：每次成功操作后自动保存，支持 JSON 导入导出、进度校验和二次确认重开。
- 界面：原创 SVG 山水、响应式布局、原生键盘可用对话框、角色状态、分类纪事。

存档保存在当前浏览器的 LocalStorage；本机与线上地址各有独立存档。换浏览器、换设备或清理网站数据前请先导出备份。没有账号、付费、广告和服务器存档。

## 文件

`public/realms.js` 统一定义境界、阶段与飞升；`public/engine.js` 是与页面分离的游戏规则；`public/content.js` 存放路径、装备和法宝数值；`public/app.js` 负责页面与交互；`public/style.css` 提供视觉样式。规则与扩展测试覆盖数值、战斗、完整结局和存档迁移。美术资产均随项目提供。字体优先加载 Google Fonts 的思源宋体和思源黑体，无法连接时自动使用系统中文字体，不影响游玩。

当前存档版本为 v3。v1 / v2 自动转换：原炼气初、中、后期对应一、七、十三层；金丹更名结丹；原渡劫境转为大乘同阶段；已通关角色保持通关并进入真仙。保留修为完成比例、气血灵力、物品强化、日志与进行中的战斗。原装备 ID 和 LocalStorage 键不变，不必重新开局。

境界顺序参考[原著境界资料](https://rmji.wiki/zh/faq/cultivation/)；本版止于原著渡劫飞升，不包含《仙界篇》的金仙、太乙、大罗、道祖后续成长。分层、资源与突破数值为本游戏设计。

完整设计见 [GAME_DESIGN.md](GAME_DESIGN.md)。本版为单机可玩首版；宗门、装备随机词条与长篇主线作为后续内容扩展方向，未伪装为可用入口。
