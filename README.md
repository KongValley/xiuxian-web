# 问道长生

一款可直接游玩的水墨风单人文字修仙游戏。由选择推进时间，无强制等待；从青云山洞府起步，历经十八次破境，走向羽化登仙。

## 启动

安装 Node.js 18 或更新版本，无第三方运行依赖。

```powershell
npm.cmd run dev
```

打开 http://localhost:4173 。`npm.cmd test` 运行规则测试；`npm.cmd run build` 生成 `dist/`，可部署到静态网站托管平台。也可执行 `node scripts/server.mjs`。

## 已实现玩法

- 洞府：吐纳、三日闭关、静养、采药与突破。
- 山河：四张按境界解锁的地图，随机论道、遗藏和回合制战斗。
- 藏经阁：吐纳、剑术、炼体三类功法，各五重。
- 坊市与行囊：购丹、服丹、出售灵材、采药炼丹。
- 成长：六大境界各三阶段，十八次突破后达成飞升结局；六个一次性里程碑任务。
- 存档：每次成功操作后自动保存，支持 JSON 导入导出、进度校验和二次确认重开。
- 界面：原创 SVG 山水、响应式布局、原生键盘可用对话框、角色状态、分类纪事。

存档保存在当前浏览器的 LocalStorage；本机与线上地址各有独立存档。换浏览器、换设备或清理网站数据前请先导出备份。没有账号、付费、广告和服务器存档。

## 文件

`public/engine.js` 是与页面分离的游戏规则；`public/app.js` 负责页面与交互；`public/style.css` 提供视觉样式；`tests/engine.test.mjs` 覆盖数值、战斗、存档与完整飞升。美术资产均随项目提供。字体优先加载 Google Fonts 的思源宋体和思源黑体，无法连接时自动使用系统中文字体，不影响游玩。

完整设计见 [GAME_DESIGN.md](GAME_DESIGN.md)。本版为单机可玩首版；宗门、装备随机词条与长篇主线作为后续内容扩展方向，未伪装为可用入口。
